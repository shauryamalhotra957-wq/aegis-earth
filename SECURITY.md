# Security policy

Aegis Earth is a decision-support web prototype.

- Never commit provider keys, private geospatial data, or credentials in source, fixtures, screenshots, or build output.
- Treat imported coordinates, scenario data, and external feed responses as untrusted input.
- Validate and bound data before rendering maps, calculations, exports, or URLs.
- Keep synthetic demo data clearly separated from any future operational source.
- Do not use prototype risk scores as emergency, medical, or environmental compliance decisions without expert review.

Report injection, sensitive-data disclosure, authentication issues, or unsafe external-link handling privately to the repository owner.
